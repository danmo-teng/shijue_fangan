# 绿色审核、近远选择与扫障点微调

基于codex/gamepad-teleop@11a17e3，按本轮用户三个要求增量；未启设备、动车或清日志。

- **绿色爪内审核：** 只需检测矩形与人工ROI重叠≥60%，取消脚点在内要求。其他类别继续原条件，橙色80%/中心及闭爪混装例外保留。绿色闭爪证据缓存、ROI编辑器预览同步；脚点在外时按框中心左右归侧。没有写人工ROI坐标/模型配置。
- **绿色选目标：** 同一帧候选若都有地面距离，按地面距离；否则若都有适用105°/120°分区值，按现有分区推进距离；否则统一按图像脚点靠下优先。缺值不再变成无穷远；同档以脚点细排，独立性次级。分区值/像素排序都是接近代用量，不能当独立地面真值。近绿属物堆时，首趟仍走原聚堆靠近/整爪审核，不跳过它去追远处独立绿；首趟后的绿对黑/橙类别优先级不改。
- **锚点与丢失：** 原ID仍在时不因新近绿而换目标；换ID沿原空间连续性，绿色额外复用已有位置/面积包络，单个远绿也不能直接借旧身份；多候选不明确时视为缺帧。原缺帧窗口内保留最后请求，窗口后清旧目标、沿现有HOLD/下位恢复回SEARCH重新选择。无新时间资格、附加等待、反复握手、FAULT或停机锁存。已提交的mode53定距原报文保持，目标漏检不重开行程；真实到夹内审核仍优先于远目标跟踪。
- **扫障点：** 转后车中心距左围栏54→56cm、距后围栏94cm保持。3m场地中心原点下，红方S=(-0.56,+0.94)m，蓝方S=(+0.56,-0.94)m。各轴±3cm容差、停稳交接、先后退再左移及后续路线保持；H/D由原上位路径计算，串口合同不变。
