源码已确认的缺口：

- 每帧重新算inside_safe_zone；安全区这一帧没检测到时，缓存框被标为blocked，内部排除也不用，之前判过区内的同一物块会重新成为候选。

建议必须同时覆盖：搜索选目标、靠近续接、发送定距前。已明确在安全区内的物块，不能因下一帧漏掉安全区就马上重新合法；当前目标重新被确认在区内时应明确结束本次追逐，不能按普通漏框继续旧坐标。抬头看全仍可用于区内外不清的情况，但本局已抬到105°且有区框，仅加抬头不足。

此方案的实际取舍：区内记忆不能粗暴按“附近同类”扩到区外邻块；如果同一物块确实被移出，应由真实区外证据解除。已有编号串错问题也意味着不能盲信永久ID黑名单。已接受mode53后怎样取消并回搜索需要核对两端：HOLD不等于撤销有限运动，当前RETURN入口也不覆盖任意靠近。先确定业务出口，不用全局STOP/FAULT代替本批结束。本轮只定位并记录，尚未实施。

## 4. 每次投送后交替转圈方向
