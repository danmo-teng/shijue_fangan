# 本阶段定位技术上下文

更新：2026-11-05。从原AGENTS分离，只有任务涉及相应实现时读取。
以下是当前阶段约定及实现边界，不是永久架构要求，也不是新任务授权；新代码证据或用户决定可更新。
历史文件不能反向覆盖当前用户要求。参数与实际实现仍须核对代码/生效配置，不把文档当实测通过。


- 用户已指定将桌面动态定位链迁移正式比赛，并选择保留正式起点/航向参考。当前直接复用RadarWorker/DynamicFence/MotionSource，正式JSON/0x16同源；测试自由初始化保持原样。见COMPETITION_DYNAMIC_LOCALIZATION_20261105.md。原YOLO26、业务动作和任务配对保留，安全区无框仅增加回放，不实施扫描/人工重试。
- 不做安全区分段轮式清零，不恢复通用ESCAPE，不新增永久STOP锁存，不覆盖mode51恢复。
- T265单一SDK设备所有者、底盘UART单一客户端所有者；雷达与T265并行验证也不得各开一个底盘UART。
- 当前T265安装参数和比例保持：r_BC=(-0.0346105,-0.0599471445,0)m，
  forward_C=(0.8660254,0,0.5)，up_C=(0,-1,0)，比例关闭/1.000；pose jumping开启。
  用户本轮明确T265相对常见正装画面翻转180°；此上下倒装已由up_C=-Y_C表达，与俯视顺时针30°分开，不再次叠加180°。
- 官方速度输入按`v_C^C=R_CB*(v_B^B+omega_B^B×r_BC^B)`一次换算；SDK源T/W=0，
  输出C→B单独处理一次，不重复内部IMU偏移。不增加外部“T265位置×权重＋轮式位置×权重”。
- 当前动态测试已按用户选择加入显式来源切换：正常T265锚点＋未覆盖区间的实测轮反馈续推，空间冲突时轮速＋主yaw传播、雷达约束可观轴。
  恢复先用运动/双轴墙一致性确认并平移重对齐；原始T265单独记录显示，不以年龄门控、不停车。工程阈值与验证状态见T265_DYNAMIC_FALLBACK_20261104.md，不视为永久标定。
- 雷达STL50B2倒装与原外参不变。动态测试的新约定：推荐在场地中心附近无遮挡处启动，不要求精确点位；
  场地中心为(0,0)，雷达估计初始XY/航向，在四个90°等价解中按初始车头最接近+X/0°选分支，保留真实夹角，
  暂不识别红蓝/实际四边身份；之后固定该分支，用主yaw传播。正式比赛坐标仍按其自身阶段决定。
- 减速带和越障会遮挡围栏/破坏平面雷达假设。雷达不可用时不更新墙面XY，继续当前选定运动来源/主yaw传播并记录缺约束；
  恢复后重新检查可观测墙，不把障碍物表面或小残差自动当围栏。当前只有人工越障暂停/恢复标记，不能称自动遮挡识别已完成。
  不为此新增永久STOP锁存，不把坐标初始化变化当作下位机FAULT修复。
- 日志在RDK，按最近5次完整模块会话保留；保护当前、不完整、明确保留会话及额外用户文件。
  分析期间不运行清理。`vision/456`和未跟踪“雷达与融合”目录是用户资料，不修改/清理/顺手提交。
- 不自动启动电机或擅自重复实车动作。复用原地图，由用户主动操作；独立真值由卷尺/地面标线提供，M冻结、G录入。
- `turn_and_return`使用T265估计生成返程目标，不能作为独立精度真值。

## 内部人工输入模式说明

- 既有内部模式可注入人工/错误速度以观察SDK响应；是否使用按本轮任务授权，不从本记录自动启动实验。
  样本必须标记synthetic来源，不能冒充F405实测。
  这是助手内部自测，不让用户在人工实测时操作错误数据注入；默认用户页面不提供此入口。
  此模式不得打开底盘UART/发送运动，复用唯一T265 SDK所有者；后续真实测量不能沿用其轨迹作纯T265基线。
  人工输入响应不等于实车精度或真实轮反馈验证，不能为了“响应好看”调小噪声或关闭pose jumping。
