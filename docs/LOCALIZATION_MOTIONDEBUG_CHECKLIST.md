## A：确认未注入的原生T265（新的SDK会话）

结束全部正式预热/地图后，先由人重插一次T265建立干净设备基线。只关闭地图保留或停送旧速度不算清空设备历史。命令仍用原入口：

```bash
python3 /home/sunrise/RDK_X5/shijue_fangan/localization/tools/t265_f407_motion_map.py --baud 921600 --wheel-input off --fisheye-evidence --reference-description '0.5m卷尺线及地面角度线；每段停稳后M冻结/G录入实际值' --fullscreen
```

先只读实报service/baud/SHA及07/08区间。确认界面OFF、SDK实际接受0；不是据此添加新的发车资格门。一次动作完成后停稳，M冻结，G填`前向mm,左向mm,实际转角deg`，未知填?。速度先200mm/s，距离改500mm；独立记录每段起终点。

按顺序单次点击：前500mm → +180° → 前500mm → 后500mm → +360° → −360°。每段均记录实际角度/位移，旋转记录车中心是否真实移动。随后左/右各300mm核对符号。需要视觉证据时C只录两次短鱼眼；不以confidence=3当准确。

不要用“转向返航”作为精度证明，它的返航距离依赖T265。A结束保存退出，记录SDK session、USB是否确实重插及actual固件。

再用同一场地、当前速度做一次短时部分视觉受扰；记录何时遮挡/移开及实测位移，不许把完全遮挡仍可定位作为验收承诺。用户要求最小仲裁方案及简洁有效测试。轮滑验证只需在相同0.5m线段做一次可控打滑对照，并记录墙面实际位移：应只有墙面支持T265且轮式偏差明显时才暂停SDK输入、继续Pose与控制；无墙/单墙不裁决完整XY。消除打滑后同线真实移动0.5m核对恢复。静止合成暂停已经验证，不重复整套；不自动执行此动作。

单墙/短时雷达不可见时记录实际可观测轴；雷达恢复后检查围栏重获。来源降级、T265跳变、车中心旋转闭合、轮式参考必须分开标注；已注入轮速的T265和轮速不再是两路完全独立真值。
