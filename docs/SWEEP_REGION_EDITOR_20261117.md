# 扫障闭合区域标定

更新2026-11-18。原桌面识别区域编辑器画完整闭合区域，115°/120°分开保存。按用户最新确认：蓝色危险目标看识别框中心，绿/黑/橙看框底边中点，判定点在区域内才参与扫障。

操作：打开原ROI工具，人工把相机调到115°或120°，选对应“扫障115°/120°”，点“清空本区域”，沿实际地面判障通道的完整外轮廓连点或按住左键描一圈，自动连接首尾。填色范围即区域，支持凹形；加密点能描曲边，不做自动平滑扩张。右键或“撤销上一点”撤点，C清空当前角度，S或“保存本角度”保存。两角分别标定；不操纵相机舵机。

预览蓝色框中心、其他类别框底边中点，用IN/OUT标区域内外；与正式扫障共用同一个取点函数。这个预览只表示几何位置，正式程序仍先排除已确认载荷/安全区内目标，再按原类别和两档规则判障，不意味着所有IN都一定扫。圈区域时应围住真正车前地面通道，避开爪子/车上载荷；不要用扩大/缩小区域代替载荷身份判断。

保存位置仍为vision/config/sweep_boundaries.json，新schema2每角polygon按描点顺序闭合，无按Y排序或左右插值；新完整轮廓不随安全区框改变外形，安全区内物块排除仍由原判定执行。原schema1双线兼容读取；编辑器仅在内存显示其对应轮廓，未保存不改变原文件。保存当前角度时读取并保留其他角度，先保留带时间戳.bak再原子替换；至少三点/非零面积/不自交，保存失败不覆盖。新旧格式可同文件共存。未标定角度沿原默认矩形；本轮没有预填新范围，也没有改capture_roi或绿橙分区。

现有人工区域无需重画或重新保存；重开正式入口及编辑器即可采用蓝色框中心规则。只有用户再次保存时才更新文件中的判定点说明和对应角度轮廓。

正式比赛重开整个入口后读取保存区域。无需下位新协议；模型、抓取/分离审核、危险/同类处理、两档预备点规则不改。仅5项必要区域/编辑器检查及7项原判障相关检查，未启动真实相机、串口或底盘。
