# 可直接转交F407：af8c534抓障后回退摆头修正

核对版本：af8c534cf707e83ee29f25299c9de605950bbaf2。
本文件是下位机修改要求，不是F407代码补丁；上位机不修改下位机仓库。
两件上限、转向放置、mode42～46等协议保持，只修内部回退控制。

## 已确认的现场依据

最新一轮从启动计时：210.92秒进入CLEAR，219.29秒发审核，219.66秒发GRAB，
219.72秒后上位机持续0x13。最终F407为mode39、GRIPPER_CLOSED=1、MOTORS_ACTIVE=1、
fault=0，CLEAR正常ACK。原伤员清单保留，不是上位机漏发GRAB或继续发HOLD打断。
222～250秒，上位机T265的y仅从约0.999降至0.939 m，期间反复摆头，未回约0.53 m预备点。
现有UART没有visual_sweep_phase/轨迹索引，不能从日志判定最后卡在哪一个内部点。

## 问题位置

Task.c的VS_GRAB_OBSTACLE合爪后进入VS_BACK_OBSTACLE，调用task_sweep_reverse_trace。
同一函数还用于VS_BACK_LOAD和VS_FAILED_BACK，三条路径都要一起修。

当前实现每10 mm或航向变化5度记录一个SweepTracePoint；回退要求距离<=4 mm后
再task_sweep_turn(target.heading)，完成才弹出一个点。存在以下控制冲突：
1. 直线运动被拆成大量微小“后退—转向—后退”动作，没有连续后退。
2. 距离判断每周期重新计算，到点未锁存；转向时微小位移使距离再次>4 mm后，
   切回Motor_Move，而Motor_Move会将angle_turn.status重置IDLE，打断刚启动的转向。
3. 近距离用atan2(当前位置-目标点)实时算朝向，几毫米偏差/越过点就可能使航向剧变。
4. 已越过一个点时没有沿段完成判据，可能一直追逐已经经过的点。

## 一、改为分段回退状态机

给倒退函数增加独立子阶段，例如：
SELECT_SEGMENT → ALIGN_SEGMENT → REVERSE_SEGMENT → SEGMENT_DONE。
纯转向段可使用RESTORE_TURN；整个路线结束再恢复预备点航向H。
这只是mode39内部子阶段，不新增对上位机可见的运动mode。

SELECT_SEGMENT：
- 从冻结的轨迹中选取当前倒序运动段，一次性锁存段起点/终点、段长、段方向、目标航向。
- 合并连续近似共线、同方向的位移采样点，不能每10 mm停车。
- 去掉重复点和纯测量噪声；真正发生的转向保留为独立转向段。
- 不跨越实际大角度转向或反向运动盲目合并，不能把曲线路程当直线距离。
- 如仍保留采样点数组，可在进入回退时归并，不要求改动对上位机的协议。

ALIGN_SEGMENT：
- 只向Motor_TurnAngle提交该段锁存的转向目标，运行中等待其完成。
- 本子阶段禁止调用Motor_Move重置该转向；只在阶段进入/完成时进行一次必要的Motor_Stop。
- 已处于允许航向误差内时直接进入后退，不做无意义的零角度转向。

REVERSE_SEGMENT：
- 按锁存段航向连续倒退，用航向误差做连续小修正，不再每周期重算近点atan2目标。
- 可继续使用负forward速度和连续nav_yaw，不在此阶段调用Motor_TurnAngle。
- 按段剩余进度减速，速度基于整段而不是相邻10 mm点的距离。
- 比较当前剩余误差和进入该段时的基准，避免不断重新设置移动原点。

SEGMENT_DONE：
- 一旦满足完成条件立即锁存，停止一次、消费该段，进入下一段。
- 后续位置轻微抖动不得回到刚完成段的REVERSE_SEGMENT。
- 回退期间索引只能单调向路线起点推进，不能加入新点或重新恢复已消费的点。
- 全路线完成后恢复H一次，再进入VS_TURN_DROP / VS_FINAL_H / VS_FAILED_H对应后续流程。

## 二、用沿段进度处理到点与越点，不只追4 mm圆

对于原前进段A→B，单位方向u=(B-A)/|B-A|；倒退从B回A。
可用s=(B-P)·u计算当前倒退进度，remaining=|B-A|-s。
终点前容差内或已通过终点截面时，结合横向误差判断该段完成并锁存。
不能越过A后重新把目标航向翻转180度去追A。

中间近似直线采样点只作为进度参考，不要求恢复每个点历史航向。
预备点最终到达容差可参考已有APP_SAFE_SWEEP_RETURN_TOLERANCE_MM=30 mm，
按实车确认，不再对所有轨迹点强制4 mm。不能仅把4改大而保留反复切换的控制结构。

## 三、保持动作和协议边界

- 合爪完成后冻结路径；原点必须对应本次S，与所用Location坐标系一致。
- VS_BACK_OBSTACLE：倒退到S→恢复H→转向放障侧→前进200 mm→张爪→后退200 mm。
- VS_BACK_LOAD：倒退到S→恢复H→mode23复审→mode40。
- VS_FAILED_BACK：张爪后倒退到S→恢复H→mode46，等RETURN_CENTER，不计投送成功。
- 距离由编码器测量；转向结合现有IMU/航向闭环。不用视觉标定距离，不改为掉头前进回S。
- 0x13重复报文只ACK；不能重置回退子阶段、段原点、索引或计时。
- mode39中的HOLD保持现有ACK-only；不要重新加入Motor_Stop副作用。
- 不增加上位机额外后退命令，不改变mode39/42/43/44/45/46/23/40握手。
- 原物资找回200 mm累计预算保持，不因轨迹段切换或新APP命令重新获得额度。
- 不用新增FAULT/ABORT或简单超时跳过S掩盖回退不收敛问题。

## 四、LCD和诊断

Lcd.c的“CMD:SWEEP OK”当前表示命令接受/ACK正常，不代表扫障完成。
保留命令接受显示，另增加机械阶段显示，例如：
SWP:BACK_OBS / BACK_LOAD / FAILED_BACK
SEG:i/N  PH:ALIGN/BACK
D:剩余毫米  E:航向误差

通过下位机现有调试输出记录：visual_sweep_phase、回退子阶段、轨迹索引、
段长/剩余进度、当前及目标x/y/yaw、当前电机turn状态、实际下发forward/yaw。
如果另扩展UART诊断，必须单独定义字段并与上位机配套，不能把现有mode39冒充完成状态。

## 五、最小验证要求

1. 直线靠近约400～500 mm后抓取，能连续倒退，不在每10 mm点停车摆头。
2. 带小角度修正的靠近能倒序返回；真正的转向段仍被保留。
3. 到点后人为构造位置误差跨阈值，已完成段不能重新激活，转向不能被Motor_Move打断。
4. 轻微越过终点时能消耗该段，不突然转180度追旧点。
5. 持续重复CLEAR/HOLD不会重置路线或段执行。
6. 障碍抓后、原物资抓后、找回失败后三种后退均经过同一修复。
7. 最终接续放障/原物资复审/失败返中，原投送批次和200 mm找回限额不变。
