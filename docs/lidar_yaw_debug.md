## 场地参考和可观测性

用户明确：本轮开机物理摆放沿用**1号初始场地方向135°**。`fixture`在本次确认车停稳后，
用`offset=135°−当前有效累计yaw`建立固定参考；后续`field_yaw=local_yaw+offset`。
即使当前累计yaw不是0也能对齐；不是磁北，不改变gyro正方向，也不向下位机发归零。
重启程序/换摆放时需确认本次实物方向；中途失效、接收中断或疑似yaw复位会要求重新核对参考，
不把恢复后的开机零点自动接回原场地方向。当前无MCU epoch，不能严格排除未观测到的复位。

围栏内部/图中角坐标范围0..3m，角原点在比赛中心坐标(-1.5,-1.5)，轴方向完全相同：
`p_competition_center=p_corner−(1.5,1.5)`，yaw不加旋转。
例如角坐标(0.3,2.7)对应中心(-1.2,+1.2)m。没有最近角折叠或自动选择90°对称分支。
`seed`由操作者给附近分支；它是关联先验，不作为拟合残差或实测真值。

固定主yaw后只修正实际墙法向对应的位置。单X墙只改X、保留Y先验，主读数Y显示“—”；
单Y墙同理；两正交墙才有双轴几何候选。继承的未观测坐标只用于虚线投影，并明确记录。
所有候选都`qualified_pose=false/full_pose_valid=false`，没有将几何秩当作已标定精度或控制资格。

## 操作入口

桌面新增`雷达-主yaw-验证地图.desktop`，打开终端和本机只读地图（默认端口8766）。
**先退出T265调试地图**：两个程序共用同一套客户端代码，但不能同时占用底盘UART。
客户端独占`/dev/ttyS1`；雷达独占不同的`/dev/ttyS6`，默认230400。
打开程序不发送底盘或雷达命令；若已在出扫描数据可直接观察，否则手动`scan_start`。
没有自动改波特率或写A7永久设置。命令行等价入口：

```bash
python3 /home/sunrise/RDK_X5/shijue_fangan/localization/tools/lidar_yaw_map.py --actual-lower-mode NormalDebug --actual-lower-service MOTIONDEBUG --open-browser
```

在新终端内操作，不把以下整个示例一次性粘贴自动跑：

1. 必要时`scan_start`，它只发雷达A0、A2=3600（10Hz目标，不冒充实测频率）。
2. 人工确认地面停稳，输入`stationary 已在地面停稳`。有效gyro与原始轮计数需持续静止至少约0.5s；
   这是异常排除条件，不能代替对实物停稳的观察。
3. 车头确实处在已确认的1号初始方向时，输入`fixture 确认1号初始摆放135度`。
   其他朝向用`yaw 角度 地面基准说明`明确重新建立参考。
4. `seed X Y 分支说明`，X/Y用比赛中心坐标m，给距离真实位置约10cm内的附近先验。
   只有车**实际在**1号标准起点时才用`seed -1.35 1.35 车实际在1号起点`；程序不会自动假设这个位置。
5. 查看静止候选；对照卷尺/地面标记，用`mark 实测位置...`记录。连续稳定双轴候选后输入
   `review_static 已核对静止点云和场地分支`，这只记录人工核对阶段，不提升任何qualification。
6. 输入`phase_rotate`，再按现场布置逐条输入`turn 90 30`或`turn -90 30`等指定动作；
   **仅当操作者主动输入时发送**。应用CCW正，客户端对旧TURN线上角度反号，gyro不反号。
7. 观察回执与真实动作结束；必要时`stop`并等匹配STOPPED。确认实物停稳后再
   `stationary 已停稳且中心标记...`，记录当前雷达位置、独立地面实测转角和中心移动。
   继续转动前再次`phase_rotate`。正反90/180/360°按实际需要逐条做，本轮未自动执行。
8. `quit`退出；若本会话发过底盘动作则请求STOP，匹配回执与实物停稳分别记录。
   可在退出前`scan_stop`停雷达。没有定位STOP永久锁存，不覆盖mode51或比赛恢复逻辑。

静止核对门包含至少5个连续扫描、约0.4s覆盖、接收间隔≤0.2s、候选变化≤3cm；
它们是诊断准入阈值，不是3cm精度通过。底盘已有动作/超时恢复规则仍由唯一客户端处理。

## 时标及旋转范围

原始雷达uint16 tick、原始数据包、每个物理点ID与主机接收时刻均保留。
1ms tick及末点含义尚无现场标定；本阶段接收锚定重建始终`capture_time_qualified=false`。
当前0x1F age是打包age，不是角速度/角度源采样tick；不同SEQ也不能用来对齐扫描点。

因此本阶段**不使用旋转中的扫描修正XY**：旋转时记录原始点云、固定参考下的主yaw、
动作/回执，地图位置只是先前静止参考，主XY读数隐藏；停止后重新取得静止墙约束。
没有逐点旋转deskew，更没有平移补偿、T265位移、轮式位置融合或主yaw与T265混合。
可以核对原地转动前后、各个停稳角度的方向符号和位置一致性；不能宣称旋转中定位精度已通过。
后续若要让移动扫描成为位置测量，先解决雷达与yaw采样时标、延迟界及误差标定。

地面转角和距离必须独立记录；请求90°、DONE进度、控制用同一gyro都不是真值。
当前下位机实际固件未在线认证。0x1F恢复/重置、CRC/扇区缺口、批量积压会显示拒绝/参考失效，
只影响本调试定位参考，不接成底盘永久故障。
