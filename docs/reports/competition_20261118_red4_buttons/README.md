# 红4第二件橙和最后一次重新预热

按启动令牌配对，共有红1、蓝2（含两次重发）、红4三个正式会话。上位cc51217，三场F405实际回报1ac74f5/dirty1，同一firmware_id。13:32:28只有预热。红4为13:25:27定位目录、4e8aae开头的SDK会话，业务归档是history/20261118_133210_competition，不能仅按目录名配对。秒数为当次启动单调时间。

## 按键

1. 最后1437.757开始预热，1441.316和1442.483短3被拒，1442.96准备好，1443.13按下的4被识别为停车。业务回报competition_started=false。随后八次长3（1445.16至1483.46）全部分类为prewarm并送到界面，状态一直为stopped=true、selecting=true、session_started=false。operator_panel.tick和prepare_warm_session都要求未停车，长3因此无法起新局。两次短3也因没有有效就绪按键令牌被拒。1496.11识别长4，1499.55完成回待机。期间的停车提示还把这个尚未发车的状态描述成“保留本局、短3重发”。
2. 红4末尾有两次4分别按4.84和4.95秒，只分类stop。1399.15那次按5.72秒，1404.17已分类exit_session，1416.01才记录session_reset_requested，1420.29完成。1408–1409秒四次短3已被识别，派发时STOP代号已经变了。原始按键记录的dispatch时间是按键事件时刻，界面实际处理延迟应和startup事件对齐。现有证据只能把延迟定位在事件识别之后，无法从日志拆出GUI阻塞的每一秒。
3. 同一入口采到37次3号按下、21次4号按下，已记录的3/4中无小于30ms的按下及组合键锁定；采样间隙内的物理脉冲不能统计。蓝2两次短3重发均生成新起点参考，实际重新进入比赛。更早的13:09定位预热退出码3，是另一例RealSense异常出口，设备报错详情未保存在该会话。
4. 最小待选方案为明确区分“开赛前STOP”和“已开赛STOP”。开赛前STOP后提示准确的下一步，可考虑松开4后允许重新长3只预热。已开赛STOP继续原保局。达到长4阈值时给操作反馈；清局完成后再接受下一轮预热。记录GUI实际取出事件的时间才能进一步定位排队延迟。规则变化待人确认。

## 红4第二次正式运橙

- 1146.34开始返航，1146.52已进预备点复审。约0.57秒复审结束。1153.845下位mode10/op5开始推进，1156.308已mode12准备放下，1156.965为mode15，1158.02上位视觉1秒超时请求完成，随后下位mode16，1162.03恢复搜索。没有把旧区内橙算作本趟成功。按0x07实测速度及MCU采样区间积分，进入动作至1155.476约40.1cm，到1156.299约67.2cm，与下位原67cm轮程结束一致，未到前段4秒或尾段1.5秒保护时间。轮程并非地面真值。片段3中已有一橙在区内，当前竖橙停在入口外侧，退出后仍可见。红1的第二次单橙则触发过门口横移滤除并有视觉提前完成。
- 1138.16、1138.26秒正常局部雷达解Y约0.091m。1138.36局部解失去可用轴，二维重定位提出Y=0.400m，1138.46第二个相近解Y=0.402m被采用；与该帧运动预测Y=0.092相差+31.1cm。程序按当前固定航向检查两面围线，两次新扫描的候选偏移相差≤5cm就采用。它们恰好连续看到同一内侧线，次数一致并不足以确认其物理身份。
- 复算原始点，沿原安装窗口、外参、线提取，以记录的扫描参考航向、附近0x08角度和0x07速度补偿圈内运动。旧地图上Y线从1138.26秒的Y约1.50m、X约0.42至0.86m，换成1138.36/46秒的Y约1.19m、X约−0.23至+0.34m。该线很符合中部红区前缘（模型内缘Y=1.20m），识别为Y=1.50m外圈墙会把车的位置向红区推约31cm。具体是哪一条实体边缘属于几何推断。1138.76至1155.77期间没有Y轴修正，1140–1154秒140帧全部仅X。1155.87相对两面墙恢复Y：0.989→0.707m，−28.3cm，可这时已推进约52cm，F405按整段轮程收尾。进区前车头已回报89.35°，推进方向为+Y。
- 本局另一项双墙yaw修正+6.44°在1041.59秒已经采用，比上述跳变早约97秒；跳变记录为固定yaw的XY重定位，不能把31cm直接算在yaw动作上。红4整局约97%扫描至少能校一个轴，门口仍可能丢失所需的Y轴。
- 建议先用这两个扫描验证二维重新定位的墙身份：以最近可信的该轴位置和已测运动为参照，遇到中部安全区前沿与外墙平行的歧义时，保留原轴并等额外围栏证据；对相反墙距等独立证据仍允许恢复。别用连续多看同一条线代替墙的身份证据。此为候选方案，本轮仅分析，未改参数或运行代码。

## 后墙是否可见与离线复核

以误定位前的运动预测投影，统计后墙Y=1.50米附近±3.5厘米的同一连续点组。1138.26秒右侧有25点，X约0.27–0.88米，程序采用外墙。1138.36、1138.46秒分别仍有14点跨约28厘米、5点跨约8厘米，均不足以单独形成合格墙线。10月31日278370a的原版要求至少12点、5%至95%跨度至少35厘米，才参加同侧平行线择远。把相同的去畸变点交给原版与当前提线，两者在这两帧均只提到Y约1.19米的横边。11月4日79ae68c加入失去局部位置后，两次偏移一致即可采用双轴围栏解。

本轮在这个重新定位出口区分红蓝前沿：按原运动预测，若本侧横线落在地图前沿1.14–1.20米及原墙拟合误差范围内，且没有一段可靠支撑延伸到左右宽度外，只接纳独立X证据，Y沿用运动推算。相对墙距证据和正常可见的外围栏沿原入口采用。红4从1138.16至1155.87秒逐扫描按记录的运动增量继续回算，原跳变帧只修X，Y为0.0917米；约17.7秒窗口的最大单次Y修正约6.2厘米。独立带入当时已偏的Y，1155.87秒原有相对墙恢复仍得到约0.707米。这是原始点和运动日志的离线复算，不是实车地面坐标真值。
