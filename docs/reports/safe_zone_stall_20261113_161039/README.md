## 为什么没抬高复看

state_machine.py当前与实跑版相同：

1. ACQUIRE_SAFE_ZONE阶段有两条原复看入口：5秒未获得所需安全区框，或顶部裁切框的连续识别被漏检打断。
   此处会设置safe_zone_view_pitch_cdeg=11500并发0x04/arg_b11500。
2. 一旦成功识别，立即进入ALIGN_SAFE_ZONE_BY_LOCKED_BOX。
3. 该阶段遇safe_bbox=None、safe_zone_filter_blocked或相机角度不匹配，只return PAUSE。
   没有设置11500，也没有接回ACQUIRE，所以等多久都不会走原5秒复看分支。

本段目标视角与实际回报均12000；末次vision.safe_zone_filter_blocked=false但没有当前安全区框，
并非角度回报不符导致的同名reason。直接停止条件是当前安全区分区点不可用。
这属于上位状态衔接缺口，不是最后这段115°命令发出后被下位拒绝。

同一局214.832s确有safe_zone_acquire_no_box，原始命令opcode4/arg_b11500；
214.874s原始0x17角度字段已变11500，214.903s回放也记录11500，随后完成识别并推进。
此字段是下位报告的命令角度，不是独立舵机位置测量；不能把它当作物理转角精度验收。
最后卡段并未请求11500，符合用户未看到该段抬镜的现象。
130.961—147.148s还有一段16.187秒的同类视觉ALIGN停顿，留存131帧仅27帧有safe_red，亦一直12000。
