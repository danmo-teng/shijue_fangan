# 启动界面整轮复位

在地图/启动窗口或由它启动的完整比赛识别窗口按 R（大小写均可），停止识别任务，再停止定位与串口转发；归档上一轮日志，清除旧定位、下位机状态和待发命令。界面回到所选出发位，清空轨迹，保留红蓝方、出发区、进攻/防守及定位设置。R 不再是选红方或单纯清轨迹；颜色仍可点击按钮选择。

识别窗口将带本轮令牌的复位请求转发给启动窗口，启动窗口统一执行复位；过期请求不能复位下一轮。独立命令行启动、没有所属启动窗口的识别进程不执行整轮复位。识别日志记录 `session_reset_forwarded`；`rescue_map/runtime/startup_events.jsonl` 记录 `session_reset_requested` 和 `session_reset_completed`，后者表示进程停止及上位机复位已完成，并不表示下位机已重新上电。

将车摆回所选出发位并给 F407 重新上电后，按 Enter 或点击“确认并开始”。重新启动定位，在新鲜有效定位就绪后启动完整识别任务，沿用原赛前配置握手和 WAIT_START，任务计数、首件标志及跟踪上下文重新建立。运行中重复 Enter 不会重复启动进程。定位启动失败时不启动识别。

R 显示的是出发位理论初始姿态，不伪造有效定位输出；Enter 启动的新定位进程重新建立实际定位参考。复位期间不要让车继续自主运行。此功能只管理本界面启动的进程。

进攻藏点距对方围栏由40 cm增加到45 cm，红方目标(+0.15,-0.69) m，蓝方目标(-0.15,+0.69) m；防守和坐标系不变。

## 下位机

本次无需修改 F407。由操作员重新上电清除下位机状态，不新增软件复位命令；继续接受既有赛前配置及实时H/D导航，藏点不要写死。既有动作完成、审核与运输协议均不变。
