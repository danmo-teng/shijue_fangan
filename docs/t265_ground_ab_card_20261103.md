## A：纯T265

```bash
/home/sunrise/RDK_X5/shijue_fangan/localization/tools/desktop_launcher.sh --wheel-input off --timed-measurements --no-log-prune --reference-description '地面起点与车头方向标线；卷尺测车体旋转中心；逐段独立测量'
```

保持静止直到实际Pose有输出；界面应为未请求注入/API成功0。
用户先按S，看到匹配STOPPED；再设置200mm/s（默认300时J两次）、30°/s（默认60时[三次）。
每段开始前记下实际车中心/朝向的地面起点，动作结束并实物停稳后M冻结，然后G输入实测并回车。

| 顺序 | 按键/动作 | G输入含义 |
| --- | --- | --- |
| 1 | V，前进1000mm | 实测前向mm,实测左偏mm,实测转角deg |
| 2 | P，逆时针180° | 如只测角度，输入?,?,实测角度 |
| 3 | V，转后前进1000mm | 相对于本段起点车头的前/左位移 |
| 4 | B，后退1000mm | 后退的前向分量为负 |
| 5 | 0，逆时针360° | 实际观察圈数并测终点方向；同时观察中心有无平移 |

未知项填?；不能将指令值当实测。示例：实际前进988mm、左偏5mm、角度没测，输入`988,5,?`。
若发生中断/故障，本段单独记录，不按完整动作打分；不自动重跑整套。Y转向返航不用。
M记录时不再按帧年龄拒绝，保存原样本时间与pose_age_at_mark_ms，不将旧样本改成新采样。
